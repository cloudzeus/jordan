# Floorplan Editor — Βελτιώσεις σχεδίασης & επεξεργασίας

## Τρέχουσα κατάσταση

Ο editor έχει δύο μοντέλα δεδομένων:

- **v1 (legacy, compatible):** `drawnWalls: {a,b,t}[]` σε pixels + `rooms[].walls.openings`. Χρησιμοποιείται από προσφορές, PDF export, 3D.
- **v2 (vector, beta):** `WallEntity {a,b,typeId,source}` σε μέτρα + `OpeningEntity {wallId,t0,t1,...}` σε μέτρα. Ζει στο Zustand store (`lib/floorplan/editor/store.ts`) και παράγει v1 μέσω `editorSnapshot()`.

Τα κρίσιμα αρχεία:

- `components/admin/floorplan/floor-plan-dialog.tsx` — orchestrator, onPick, tool state.
- `components/admin/floorplan/plan-viewer.tsx` — Three.js canvas, draft, handles.
- `components/admin/floorplan/editor-shell.tsx` — toolbar/inspector chrome.
- `lib/floorplan/editor/store.ts` / `reducers.ts` — v2 data & mutations.
- `lib/floorplan/editor/snapping.ts` — endpoint/segment/axis/grid snap.
- `lib/floorplan/editor/interactions.ts` — pick, marquee, canvas mapping.
- `lib/floorplan/saved.ts` — PlanData v1/v2 schemas.

## Προβλήματα που περιγράφεις

1. **Δεν μπορείς να συνεχίσεις/κολλήσεις τοίχο από εκεί που τελείωσες.**
   - Στο v2 wall tool υπάρχει endpoint snap, αλλά το UI δεν το κάνει προφανές· δεν υπάρχει «extend wall» ή «start from endpoint» affordance.
2. **Καθόλου αλλαγές σε τοίχους μετά.**
   - Υπάρχει μόνο drag άκρων (`onWallEnd`) χωρίς visual handles, χωρίς move whole wall, χωρίς split/merge/trim.
3. **Πολύ δύσκολη επιμέτρηση.**
   - Το measure tool δεν κουμπώνει σε άκρα/τμήματα, δεν δείχνει ζωντανά snap, δεν έχει καθαρή ετικέτα.
4. **Δεν υπάρχει τρόπος να ορίσεις ανοίγματα πάνω στους v2 τοίχους.**
   - Το opening tool δουλεύει μόνο πάνω στα περιγράμματα των v1 rooms.
5. **Zoom χωρίς κουμπιά.**
   - Μόνο wheel/pinch· δεν υπάρχουν +/- / fit buttons που να δουλεύουν ενώ σχεδιάζεις.
6. **Το πάχος/ύψος του τοίχου δεν είναι φανερό κατά τη σχεδίαση.**
7. **Δεν υπάρχει κολώνα / τοιχίο ως οντότητα.**

## Προτεινόμενη λύση — 4 φάσεις

### Φάση 1: Σχεδίαση τοίχων που δεν σε κόβει

Στόχος: το χειροκίνητο «τράβα τοίχους» να είναι γρήγορο και σταθερό.

- **Zoom controls πάνω στον καμβά:**
  - Κουμπιά `+` / `-` / `↔ χώρεσέ το` σε fixed position (π.χ. κάτω δεξιά).
  - Δουλεύουν ενώ σχεδιάζεις wall/measure/opening (το draft δεν χάνεται).
  - `Space` drag ή δεξί κλικ-drag για pan, ώστε το αριστερό κλικ να μένει για σημεία.
- **Visible wall type & thickness:**
  - Το ενεργός τύπος τοίχου δείχνει `όνομα + πάχος` στο status bar / toolbar.
  - Chips γρήγορης εναλλαγής (1-9) με highlight.
- **Wall type persistence:**
  - Αποθήκευση `typeId` στο v1 `drawnWalls` (προαιρετικό πεδίο) ώστε να επιβιώνει πάχος/ύψος.
  - Ή migration του `savePlan` να στέλνει το πλούσιο v2 snapshot.
- **Τοιχίο ως έτοιμος τύπος:**
  - Προσθήκη wall type «Τοιχίο» (π.χ. 10cm πάχος, 1.0m ύψος) στο seed catalog.
  - Το ύψος ανά τοίχο πλέον επιβιώνει.
- **Continue/extend wall:**
  - Όταν το wall tool είναι ενεργό και hover κοντά σε άκρο υπάρχοντος τοίχου, προβάλλεται highlight + tooltip «Κούμπωμα σε άκρο».
  - Κλικ πάνω σε άκρο ξεκινά νέο τοίχο από εκεί.
  - Νέο εργαλείο/shortcut **Extend** (π.χ. `Ctrl+E`) που κάνει κλικ σε άκρο και τραβάει συνέχεια.

### Φάση 2: Επεξεργασία τοίχων

Στόχος: μετά τη σχεδίαση να μπορείς να πειράξεις τοίχους χωρίς να τους ξανασχεδιάσεις.

- **Select tool βελτιωμένο:**
  - Κλικ σε τοίχο = επιλογή, Shift+κλικ / Shift+marquee = πολλαπλή.
  - Επιλεγμένος τοίχος δείχνει λαβές στα άκρα a/b και στο κέντρο.
- **Drag άκρων (ήδη υπάρχει, αλλά χωρίς handles):**
  - Ορατές λαβές στα άκρα, με snap.
- **Move whole wall:**
  - Σύρσιμο στο κέντρο του τοίχου μετακινεί ολόκληρο το τμήμα (και τα openings του).
- **Change wall type:**
  - Στο δεξί inspector: dropdown/chips με τους τύπους· εφαρμόζεται στον επιλεγμένο/ους.
- **Split wall:**
  - Κλικ πάνω σε τοίχο (ή λαβή «σπάσιμο») τον χωρίζει σε δύο τοίχους στο σημείο.
- **Merge walls:**
  - Επιλογή δύο συνεχόμενων, συνευθυγράμμιων τοίχων → κουμπί «Ένωση».
- **Trim/extend to intersection (nice-to-have):**
  - Κουμπί «Κόψε έως τοίχο» για CAD-style trim.
- **Delete:**
  - `Del` / Backspace διαγράφει επιλεγμένους τοίχους (με cascade στα openings).

### Φάση 3: Ανοίγματα πάνω σε v2 τοίχους

Στόχος: πόρτες/παράθυρα να ορίζονται απευθείας πάνω στους vector τοίχους.

- **Opening tool v2:**
  - Δύο κλικ πάνω στον τοίχο (ή drag) ορίζουν το πλάτος.
  - Inspector: είδος (πόρτα/παράθυρο/άλλο), ύψος, ποδιά, άνοιγμα φύλλου (αριστερά/δεξιά).
  - Το opening αποθηκεύεται στο v2 `openings[]` και εμφανίζεται σε 2D/3D.
- **2D visualization:**
  - Πόρτα: τόξο/κύκλος φύλλου, χρώμα `#F59E0B`.
  - Παράθυρο: διπλή γραμμή, χρώμα `#38BDF8`.
- **3D / export:**
  - Το `editorSnapshot()` ήδη υπολογίζει openings από v2· χρειάζεται verify ότι κόβει σωστά τα wall pieces.

### Φάση 4: Κολώνες & επιμέτρηση

Στόχος: ολοκληρωμένη αρχιτεκτονική σκιαγράφηση.

- **Κολώνα ως νέα οντότητα:**
  - Νέο εργαλείο «Κολώνα» στο toolbar.
  - Κλικ = τοποθέτηση τετραγώνου/ορθογωνίου· διάσταση από επιλογή (π.χ. 20×20, 25×25, 30×30 cm).
  - Αποθήκευση σε νέο πίνακα `columns[]` στο v2 (ή `columns[]` μέσα στο `PlanDataV2`).
  - Εμφάνιση σε 2D (γεμισμένο/περίγραμμα) και 3D (κουτί).
- **Βελτιωμένη επιμέτρηση:**
  - Measure tool κουμπώνει σε άκρα τοίχων, κέντρα, κάθετα σε τοίχο.
  - Ζωντανή διάσταση με ξεκάθαρη ετικέτα (π.χ. «3,42 m»).
  - Δυνατότητα «διάσταση πάχους τοίχου» και «διάσταση ανοίγματος».

## Τεχνικές αποφάσεις

### Αποθήκευση: Δρόμος Α (προτείνω)

- Διατηρούμε το v1 `PlanData` ως επίσημο saved format.
- Προσθέτουμε προαιρετικό `typeId` στο `drawnWalls` item.
- Προσθέτουμε `columns[]` και `openings[]` στο v1 για backward-compatible export.
- Το v2 store παραμένει in-memory· το `savePlan` στέλνει το πλούσιο snapshot μέσω `editorSnapshot()`.

Πλεονέκτημα: δεν σπάμε προσφορές / PDF / 3D.

### Δρόμος Β (μελλοντικά)

- `savePlan` στέλνει κατευθείαν `PlanDataV2`.
- Προσφορές / PDF / 3D ανανεώνονται να διαβάζουν v2.

**Αποφυγή:** Δεν πάμε Β τώρα — μεγάλο ρίσκο.

## Ερωτήσεις προς εσένα

1. **Θέλεις να ξεκινήσω με όλες τις φάσεις μαζί ή φάση-φάση;** (Συνιστώ φάση-φάση για testing.)
2. **Κολώνα:** θέλεις μόνο ορθογώνια (π.χ. 20×20, 30×30) ή και στρογγυλή; Θέλεις να μετράει σε επιμέτρηση;
3. **Openings:** θέλεις να ορίζονται μόνο πάνω σε v2 τοίχους, ή και να μετατρέπονται αυτόματα από τα v1 room openings;
4. **Επιμέτρηση:** προτεραιότητα έχουν διαστάσεις «από–έως» με snap, ή θέλεις και αυτόματες διαστάσεις γύρω από έναν χώρο;
