# SoftOne custom scripts — εξαιρέσεις

> Κανόνας του έργου: **μόνο επίσημα S1 Web Services**. Τα scripts εδώ είναι **ρητά εγκεκριμένες
> εξαιρέσεις** (μία ανά περίπτωση). Μη προσθέτεις άλλο χωρίς νέα έγκριση.

## `units.js` — Μ.Μ.2 σε είδος με παραστατικά

**Γιατί:** το `setData` του ITEM απαντά «Δεν μπορεί να γίνει αλλαγή του πεδίου 'Μ.Μ.2'. Υπάρχουν
καταχωρημένα παραστατικά.» ακόμη και με χρήστη διαχειριστή. Στο client είναι ερώτηση επιβεβαίωσης, που
μέσω Web Services δεν απαντιέται. Εγκρίθηκε 17/10/2026 μόνο για αυτό.

**Τι κάνει:** γράφει **μόνο** `MTRUNIT2`, `MU21`, `MU12MODE` ενός είδους (SODTYPE 51) της τρέχουσας
εταιρείας. Δεν αγγίζει βασική μονάδα, μονάδες αγορών/πώλησης, παραστατικά ή αποθήκη.

**Έλεγχοι μέσα στο script:** επιτρεπτός χρήστης (`ALLOWED_USERS`, 14 = «webapp»), κοινό μυστικό,
έγκυρα MTRL/μονάδα/σχέση (0 < σχέση ≤ 100000), το είδος υπάρχει στην εταιρεία, η μονάδα υπάρχει και είναι
ενεργή, Μ.Μ.2 ≠ βασική, **καμία γραμμή παραστατικού με ποσότητα Μ.Μ.2** (αλλιώς θα αλλοιωνόταν το
ιστορικό), `DRYRUN` = μόνο έλεγχοι, επαλήθευση μετά την εγγραφή.

**Έλεγχοι στην εφαρμογή** (`lib/softone-sync/unit2-script.ts`): μόνο ADMIN/SUPER_ADMIN, ανάγνωση πριν
(επίσημο `getData`), dry-run, εγγραφή, ανάγνωση μετά και σύγκριση, εγγραφή στο ιστορικό ενεργειών
(`item.unit2.script`, πριν/μετά).

### Εγκατάσταση

1. **Μυστικό κλειδί** — φτιάξε ένα τυχαίο (≥ 32 χαρακτήρες), π.χ. στο Terminal:
   `openssl rand -hex 24`
   - Βάλ' το στο `.env` της εφαρμογής: `SOFTONE_UNITS_SECRET=...` (ποτέ σε chat/email).
   - Βάλ' το **ίδιο** στο script, στη γραμμή `var SHARED_SECRET = '...'`.
2. **SoftOne client** → φάκελος **skroutz** → module **units**: αντικατέστησε όλο το περιεχόμενο με το
   `units.js` (με το μυστικό του βήματος 1) και αποθήκευσε.
   - Ο προηγούμενος κώδικας του module **έγραφε χωρίς κανέναν έλεγχο** (αγνοούσε το DRYRUN) — πρέπει να
     αντικατασταθεί.
3. Αν ο χρήστης Web Services δεν είναι ο 14, άλλαξε το `ALLOWED_USERS`.
4. Η διαδρομή κλήσης είναι `…/s1services/JS/skroutz.units/setUnit2` (προεπιλογή στην εφαρμογή·
   αλλάζει με `SOFTONE_UNITS_SCRIPT` στο `.env`).
5. Επανεκκίνηση της εφαρμογής (για να διαβαστεί το `.env`).

### Έλεγχος μετά την εγκατάσταση

Μόνο έλεγχοι, χωρίς εγγραφή (ως διαχειριστής, με ανοιχτή συνεδρία στην εφαρμογή):

```
POST /api/admin/softone/items/<MTRL>/unit2?dryRun=1   { "unit2": 202, "ratio2": 52, "strict2": false }
```

Σωστή εγκατάσταση → `200 { dryRun: true, before: …, after: … }`. Λάθος μυστικό → `403`.

### Χρήση

Καρτέλα είδους → αλλάζεις Μ.Μ.2 → Αποθήκευση. Αν το SoftOne την αρνηθεί, εμφανίζεται πορτοκαλί
πλαίσιο → ⋮ → **«Αλλαγή Μ.Μ.2 μέσω script»** (μόνο διαχειριστές) → επιβεβαίωση. Μετά αποθηκεύονται και οι
υπόλοιπες αλλαγές από το επίσημο `setData`.
